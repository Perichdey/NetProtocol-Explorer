# NetProtocol-Explorer
Plataforma visual e interativa de observabilidade e aprendizado de redes. Dissecação em tempo real com TShark/PCAP, classificação nas 7 camadas OSI e TCP/IP, grafos de conexões, centro de hipóteses de cibersegurança e enciclopédia modular em Markdown com Hot-Reload.
